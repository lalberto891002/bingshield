# BingeShield

Extensión Chrome Manifest V3 para bloquear dominios y patrones del hostname.

## Cargar en Chrome

1. Abre `chrome://extensions`.
2. Activa **Modo desarrollador**.
3. Pulsa **Cargar descomprimida**.
4. Selecciona esta carpeta.

La configuración está en el menú de opciones de la extensión. El PIN protege los cambios, y el historial/notificaciones son locales al ordenador.

## Pruebas

Con Node.js instalado: `node tests/shared.test.js`.
